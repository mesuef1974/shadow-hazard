# مراجعة مستقلة

افحص المطلوب والفرق كاملًا، ثم راجع السياق والاختبارات والمسارات المتأثرة. أبلغ فقط عن مشكلة محددة تؤثر في الصحة أو الأمان أو الأداء أو قابلية الصيانة، ويمكن ربطها بالتغيير ومشهد حدوثها.

رتب النتائج حسب الشدة، واذكر الملف والسطر والسبب والأثر. لا تعدل الشفرة ولا تخلط الاقتراحات بالعيوب. اختم بحدود المراجعة والاختبارات التي لم تُشغّل.

هذا الملف نسخة مشروع من المهارة المثبتة محليًا في Codex، وأضيفت لتظهر ضمن مهارات المستودع.
