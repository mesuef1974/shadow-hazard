# مقترحات الهوية — غير معتمدة

[افتح صفحة المقارنة](index.html). الصورة concept-board.png مولدة كلوحة تصور ولا تعتبر ملفات شعار نهائية أو نموذج تميمة ثلاثي الأبعاد. SVG رسم رمزي مبسط للاتجاه الأول، وليس تتبعًا مطابقًا للوحة.

الألوان والخطوط في directions.json هي المصدر المنظم للمقترحات، ومنها تُولّد tokens.css. الألوان الخاصة بالحالات التشغيلية (الخطر/فقد البيانات/نجاح العملية) طبقة دلالية مستقلة عن ألوان العلامة. لا نستخدم الكهرماني أو الأخضر وحدهما لإثبات خطر أو أمان.

الخطوط مستضافة محليًا في fonts مع ملفات OFL ومصادر وبصمات؛ لم تثبت على النظام. قبل الاعتماد نراجع أحجام الشعار الصغيرة، أحادي اللون، النسخة العكسية، الكتابة العربية/الإنجليزية، القوالب، وعينة طباعة فعلية. قيم CMYK تعتمد على ملف ICC والمطبعة؛ لا نحسب تحويلًا عامًا وندعي مطابقته.

الأصول المقترحة بعد الاختيار: شعار أفقي ومكدس ورمز مستقل وأحادي وعكسي، favicon، تميمة كاملة ورأس وثلاث وضعيات، قالب تقرير وملصق وشرائح، ومكتبة مكونات. الهوية الحالية في صفحات التوثيق السابقة مؤقتة، ولا يصبح أي اتجاه معتمدًا تلقائيًا.

استخدمت إرشادات logo-designer وmascot-logo وui-ux-pro-max وfrontend-design. أُخذت مبادئ التباين والوضوح والتكرار وقابلية استخدام الشعار؛ اقتراحات المهارات ليست قرار اعتماد. تحتوي مهارات Logo Designer على تذييل تسويقي تابع، موثق في جرد المهارات، ولم يضف إلى أصول المشروع.
