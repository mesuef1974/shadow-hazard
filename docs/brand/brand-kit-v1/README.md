# ظل الخطر — حزمة الهوية البصرية والعلامة التجارية

**Shadow Hazard · الإصدار 1.0 · نوفمبر 2026**

هذه الحزمة مبنية على الشعار القديم الذي اعتمده صاحب المشروع. تحتوي صيغ إنتاج مشتقة من الأصل، ونظام ألوان وخطوط وأيقونات وتطبيقات ودليلًا عربيًا. تميمة «راصد» موجودة بصورتها الأصلية دون إعادة رسم. جميع مقترحات الشعار اللاحقة، بما فيها تحويل الجدار إلى حافلة، مستبعدة.

## ابدأ من هنا

1. افتح `guidelines.pdf` لعرض دليل الهوية العربي ذي **26 صفحة**.
2. شاهد `applications/applications-overview.png` لمراجعة التطبيقات معًا.
3. استخدم `logo/logo-original-color.svg` مرجعًا متجهيًا لتكوين الأصل، أو اختر الصيغة المناسبة من `logo/`.
4. للمطور: حمّل `colors/tokens.css` ثم `typography/typography.css` مع ملفات الخط المحلية، واستعمل الأيقونات من `icons/`.
5. للتعديل على النماذج: افتح SVG المناسب في `applications/templates/` بعد تثبيت الخطوط؛ وهو المصدر المباشر لصور PNG.

**احتفظ بترتيب المجلدات عند فك ZIP:** تعتمد مصادر التطبيقات والدليل HTML على روابط محلية نسبية.

## صيغ الشعار

كل اسم في الجدول موجود بصيغتي SVG وPNG شفاف. النص داخل SVG الخاص بالشعار مسارات؛ لا يحتاج إلى تثبيت خط، ولا يحتوي صورة مضمّنة أو تدرجًا أو فلترًا.

| الاسم | الاستخدام |
|---|---|
| `logo-original-color` | تكوين الصورة الأصلية ومواضعها، بخلفية شفافة |
| `logo-vertical-color` | القفل العمودي الأصلي، مع قص الفراغ الخارجي |
| `logo-horizontal-color` | الرمز إلى يمين كتلة الاسم والعبارة |
| `symbol-color` | الرمز وحده |
| `logo-mono-navy` | القفل العمودي بحبر كحلي واحد |
| `logo-reversed` | القفل العمودي الأبيض للاستخدام على الكحلي |
| `logo-horizontal-reversed` | القفل الأفقي الأبيض |
| `symbol-mono-navy` | الرمز الكحلي |
| `symbol-reversed` | الرمز الأبيض |
| `app-icon-512` | أيقونة تطبيق 512×512 من الرمز الأصلي |
| `favicon-16` | رمز المتصفح 16×16 |
| `favicon-32` | رمز المتصفح 32×32 |

`favicon.ico` يتضمن المقاسين 16 و32. ملف المعكوس شفاف فعلًا؛ اللون الأبيض يظهر عند وضعه فوق خلفية كحلية.

### ما معنى «مطابق للأصل» هنا؟

الشخص والكتلة والخطان والدوائر والكتابة استُخرجت من حدود الصورة المعتمدة، لا من إعادة توليد تخيلية ولا من إعادة كتابة الاسم بخط بديل. النسخة الأصلية تحافظ على لوحة 1536×1024 ومواضع العناصر. القفل الأفقي يغيّر ترتيب المجموعات فقط، مع تحجيم موحد دون تغيير النسب الداخلية. الأحادي والمعكوس هما صيغتا اللون المطلوبتان صراحة.

لأن المرجع المتاح PNG، أُعيد بناء الحدود بمنحنيات Bézier؛ تظهر فروق تنعيم صغيرة عند المقارنة البكسلية، وليست هناك مطالبة باستعادة متجه أصلي غير متاح بنسبة 100%. فحص الحدود موجود في `validation/logo-vector-check.json`، والتفسير في `logo/NOTES-ar.md`.

### الحجم الصغير

حدود البداية المقترحة للقراءة الكاملة: عمودي 240px، أفقي 360px، رمز 96px. مقابلات الطباعة المحافظة: 64mm، 96mm، 26mm على الترتيب، مع فحص بروفة حسب الخامة.

ملفا favicon يحافظان على الهيئة العامة للأصل عند 16 و32px؛ لا يمكن قراءة كل تفاصيل الشخص والخطين فيهما. لم تُغيّر الهندسة أو تُغلّظ العناصر للحصول على نسخة مختلفة.

## الألوان والخط

| اللون | HEX | الدور |
|---|---|---|
| الكحلي | `#142D4E` | الأصل والنص الأساسي |
| البترولي | `#007F82` | الأصل والفعل الرئيسي |
| الكهرماني | `#F4B544` | إبراز وخلفية تنبيه، لا نص |
| الخلفية | `#F4F7FB` | الواجهة والورق ومساحة راصد |

درجة الرابط في الفاتح `#00696C` ودرجة الرابط في الداكن `#60CFD0` درجتان دلاليتان للواجهة، ولا تُطبّقان على الشعار. البترولي الأصلي فوق الخلفية الفاتحة يحقق 4.485:1؛ لذلك لم يُعتمد كنص عادي فوقها. جميع أزواج النص التشغيلية المختارة تجتاز 4.5:1، مع تقرير مستقل للأزواج المرجعية غير الصالحة.

الخط **IBM Plex Sans Arabic** بأوزان 400 و500 و600 و700، مرفق محليًا مع رخصة OFL. لا يستبدل رسم الاسم في الشعار. أدوار الألوان وحالاتها موجودة في CSS وJSON. JSON خريطة tokens داخلية موثقة، ولا تدّعي التوافق مع مخطط تبادل لم يُختبر.

## راصد

`mascot/rasid-original.png` نسخة بايتية من الصورة المعتمدة، 1312×1199. خلفيته الفاتحة جزء من الصورة؛ لا ندّعي أنها قصاصة شفافة. يظهر كاملًا دون قص أو قلب أو تغيير لون أو كتابة. دوره مساند في التعريف والتعلم، ولا يعرض حالة رصد حي أو يضمن سلامة الطريق.

مصادر تطبيقات SVG تحتوي نصوصًا قابلة للتحرير وصورًا مرتبطة؛ **هذا مختلف عن SVG الشعار** الذي يحتوي مسارات فقط. ملفات HTML توثيق إضافي للتركيب، وSVG هو المصدر المباشر للتصيير الذي جرت مراجعته.

املأ أسماء الطلاب والمشرف والمدرسة ورقم الوحدة قبل النشر. لم تُخترع نتائج تجارب أو نسب دقة، ولم تُضف شعارات للجهة المنظمة أو اعتماد سلامة. خريطة المنصة تخطيط محتوى وواجهات؛ الحزمة لا تتضمن تطبيقًا متصلًا بالكاميرات أو تسجيل دخول أو قاعدة بيانات.

## لغة الحالات

- **تحذير: طفل داخل ظل الرؤية** — حالة تتعلق بالحجب المحسوب.
- **الطفل ظاهر خارج الحجب** — وصف الرؤية، وليس إعلانًا بأن الطريق آمن.
- **غير متاح: تعذّر تقييم الرؤية** — يُعلن عند نقص البيانات، مع سبب وتوقيت عندما يتاحان.
- **حُفظت التجربة** — نجاح عملية بيانات منفصل عن حالة الطريق.

العبارة الأصلية: **«نكشف ما تحجبه الرؤية»**. المقترحات اللفظية الأخرى في `brand/` للمحتوى التحريري فقط، ولا تستبدل العبارة داخل الشعار.
