# أيقونات واجهة ظل الخطر

عشر أيقونات مساندة مرسومة لهذا النظام، وليست بدائل للشعار المعتمد. الشبكة 24×24، سماكة الخط 2 وحدتين، نهايات ووصلات مدوّرة، ولون افتراضي كحلي. لا صور نقطية ولا نص حي ولا تدرجات ولا فلاتر. تعتمد الضربات على `currentColor` مع لون كحلي افتراضي على جذر SVG. عند إدراج SVG داخل الصفحة، عيّن خاصية CSS `color` على عنصر SVG نفسه لتغيير اللون حسب المظهر.

| الملف | الاسم | الاستخدام |
|---|---|---|
| `bus.svg` | حافلة | اختيار العائق أو الجهاز المثبت على الحافلة |
| `child.svg` | طفل | موضع الطفل في المحاكاة أو التدريب |
| `car.svg` | سيارة | المركبة القادمة وموضع السائق |
| `camera.svg` | كاميرا | مصدر الرؤية وتوافر الإطار |
| `occlusion-shadow.svg` | ظل الرؤية | المضلع المحجوب المحسوب |
| `warning-panel.svg` | لوحة تحذير | مخرج التنبيه الخاص بالسائق |
| `unavailable.svg` | غير متاح | غياب المعطيات الكافية للحساب |
| `observation-freshness.svg` | حداثة الرصد | عمر آخر إطار أو آخر تحديث |
| `simulation.svg` | محاكاة | إعداد السيناريو والتحكم في عناصره |
| `report.svg` | تقرير | نتائج التجربة وتوثيقها |

## الاستعمال

- الحجم الأساسي 24px، ويمكن العرض على 32 أو48px مع السماكة المتناسبة. لا تعتمد 16px لهذه المجموعة دون مراجعة بصرية خاصة؛ الحد الافتراضي للأيقونات التشغيلية 24px.
- تبقى مساحة التفاعل المقترحة 44×44px على الأقل ولو كانت الأيقونة 24px؛ هذه مساحة لمس تصميمية، ولا تعني أن الرسم يجب أن يملأها.
- استخدم الكحلي في الوضع الفاتح والنص الفاتح أو البترولي الفاتح في الداكن. الكهرماني خلفية إبراز مع رسم كحلي، وليس لونًا منفردًا للأيقونة فوق الورق.
- لا تعكس الأيقونات آليًا في RTL؛ الحافلة والسيارة والكاميرا والمشهد الهندسي أشياء مادية، واتجاهها تحدده بيانات المشهد. التنقل النصي RTL، لكن ليس انعكاسًا لمشهد الطريق.
- تظهر الحالة المهمة بعنوان نصي بجانب الأيقونة، مثل «غير متاح». إذا تكرر المعنى في النص نفسه، ضع `aria-hidden="true"` على الرسم. إذا استُخدمت وحدها، يجب أن يكون للزر اسم وصول واضح؛ وجود `<title>` داخل SVG لا يغني عن تسمية الزر في كل بيئة.
- لا تستخدم «لوحة تحذير» لتأكيد الحفظ، ولا «حداثة الرصد» لإيهام المستخدم بأن هناك اتصالًا حيًا في نموذج عرض ثابت.

افتح `index.html` لمعاينة الأيقونات على خلفية فاتحة وداكنة.

## تغيير اللون في الواجهة

عند الإدراج المباشر داخل HTML، يمكن تعيين `style="color:#F4F7FB"` على SVG للوضع الداكن؛ تتبع الضربات قيمة `currentColor`. عند استخدام `<img src="icons/bus.svg">` لا ينتقل لون عنصر الأب إلى الملف الخارجي تلقائيًا؛ استخدم الإدراج المباشر أو نسخة واجهة مشتقة تغيّر لون الرسم فقط. لا تُطبّق هذه القاعدة على ملفات شعار العلامة، التي تبقى ألوانها ثابتة.
