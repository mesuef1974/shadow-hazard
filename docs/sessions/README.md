# خطة جلسات المشروع

## العدد المقترح

**8 جلسات مركزة**، مدة كل منها 60–90 دقيقة، إضافة إلى عمل تنفيذ قصير بين الجلسات. هذا العدد يعطي وقتًا كافيًا للفكرة متعددة المصادر، دون أن يحول العمل إلى اجتماعات متابعة عامة. يمكن دمج الجلستين 2 و3 إذا كان الوقت ضيقًا، لكن لا تتجاوزوا جلسة السلامة أو التقييم.

## آلية العمل المشتركة

1. قبل الجلسة: يقرأ الفريق الميثاق ويرفع أسئلته أو عينة العمل إلى الفرع/المجلد المشترك.
2. افتتاح 5 دقائق: النتيجة المطلوبة، المالك، والوقت.
3. عمل مركز 40–60 دقيقة: قرار أو نموذج قابل للفحص، لا نقاش مفتوح بلا مخرج.
4. مراجعة 10 دقائق: معاينة النتيجة والقيود والمخاطر.
5. إغلاق: تحديث موثق، عناصر عمل بمالك وموعد، وقرار نعم/لا بشأن الانتقال.

## ضوابط التعاون

- طالب مسؤول عن التنفيذ، والآخر مراجع؛ بدّلوا الدور في كل جلسة.
- المشرف يملك اعتماد نطاق السلامة والخصوصية والعتاد والبيانات والادعاءات الخارجية.
- لا يعد القرار معتمدًا حتى يسجل في الميثاق/ADR ويوافق عليه المشرف عند الحاجة.
- كل جلسة تنتهي بمخرج محفوظ، لا بمجرد محضر كلام.
- عند غياب معلومة، يسجل الافتراض ومالكه وتاريخ حسمه بدل إخفائه.
