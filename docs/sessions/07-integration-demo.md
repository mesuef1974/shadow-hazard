# جلسة 07 — التكامل والعرض

**الهدف:** وصل المحاكي والرؤية/التتبع وتقدير الخطر بواجهة عرض تعليمية واضحة.

**جدول العمل:** تشغيل من خطوة واحدة؛ تمثيل الحافلة ومجال الحجب؛ موضع المشاة والمركبة؛ مصدر وعمر القياس؛ سبب التنبيه؛ إعادة الحالة للمحاكاة.

**المخرج:** عرض متكامل قابل للتكرار، وسيناريو حي آمن دون اتصال بمركبة أو طريق.

**معيار الإغلاق:** يستطيع شخص غير مطور فهم متى اكتشف النظام الخطر، ما البيانات التي اعتمد عليها، ومتى قال إن المعلومات غير كافية.

**اعتماد المشرف:** مراجعة العرض قبل نشر فيديو أو عرض خارجي.
