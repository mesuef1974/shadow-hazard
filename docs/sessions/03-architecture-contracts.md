# جلسة 03 — المعمارية وعقود البيانات

**الهدف:** تثبيت حدود الوحدات واللغة المشتركة لتبادل المشاهدات والنتائج.

**جدول العمل:** مراجعة ADR 0001؛ تعريف المصدر والتوقيت والثقة والوحدات والإطار المرجعي؛ حالات الخرج؛ سبب التنبيه؛ معالجة المصدر المفقود أو القديم.

**المخرج:** مخطط عقود بيانات وقرار معماري محدث ومسؤول لكل وحدة.

**معيار الإغلاق:** يستطيع المحاكي ومحلل الخطر تبادل حدث واحد موصوف بالكامل دون افتراض وحدات أو توقيت ضمني.

**خارج النطاق:** اختيار بروتوكول IoT أو تخزين سحابي نهائي.
