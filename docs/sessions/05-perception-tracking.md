# جلسة 05 — الرؤية والتتبع

**الهدف:** اختيار أبسط طريقة لتمثيل/اكتشاف المشاة والمركبات في نموذج العرض.

**جدول العمل:** هل تكفي أجسام اصطناعية في المحاكي؟ هل نحتاج كشفًا مرئيًا؟ مقارنة خيارات مفتوحة المصدر وحجمها وترخيصها وتشغيلها؛ ثبات معرّف الجسم وحدود الثقة.

**المخرج:** قرار اختيار موثق، واجهة detector/tracker قابلة للاستبدال، وعينة بيانات غير شخصية.

**معيار الإغلاق:** تظهر الأجسام ومساراتها في مشهد مضبوط، وتعرض الثقة أو عدم الكشف دون إخفاء الفشل.

**اعتماد المشرف:** قبل تنزيل نموذج أو استخدام صور أشخاص أو إضافة تبعية.
