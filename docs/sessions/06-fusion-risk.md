# جلسة 06 — دمج المصادر وتقدير الخطر

**الهدف:** تقدير احتمال تقاطع مساري المشاة والمركبة وتحديد متى يكون الرصد غير كافٍ.

**جدول العمل:** مزامنة المصادر؛ ربط الأجسام عبر الزوايا؛ تقدير المسار/زمن الوصول؛ حدود freshness/confidence؛ حالات HAZARD_SUSPECTED وDEGRADED وUNKNOWN.

**المخرج:** قاعدة خطر أولية مفسرة، وسبب مرتبط بكل تنبيه، ومقاييس زمن الإنذار والفائت والكاذب.

**معيار الإغلاق:** لا يتحول غياب البيانات أو قدمها إلى حالة خضراء؛ ويمكن إعادة حساب النتيجة من سجل السيناريو.

**تنبيه:** حدود الخطر نتائج تجريبية تضبط في المحاكاة، ولا تقدم كحدود سلامة مرورية.
