# جلسة 01 — ميثاق النجاح والنطاق

**الهدف:** تحويل الاستمارة إلى هدف أولي وحدود قابلة للقياس.

**الحضور والأدوار:** الطالب أ يقود تعريف المشكلة؛ الطالب ب يراجع قابلية العرض؛ المشرف يعتمد النطاق.

**جدول العمل:** مستخدمو الحل؛ تعريف «خطر محجوب»؛ ماذا يعني «إنذار مبكر»؛ ما الذي يثبت الفكرة؛ ما خارج النطاق.

**المخرج:** ميثاق مختصر مع سيناريو رئيس، مؤشرات نجاح أولية، افتراضات ومسؤول لكل سؤال مفتوح.

**معيار الإغلاق:** يستطيع كل عضو شرح المشكلة والنتيجة المتوقعة بالطريقة نفسها، ويوافق المشرف أن العرض محاكاة لا نظامًا حقيقيًا.

**خارج النطاق:** اختيار كاميرا أو وعد بنسبة دقة قبل بناء خط أساس.
