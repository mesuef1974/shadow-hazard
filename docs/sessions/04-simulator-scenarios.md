# جلسة 04 — المحاكي والسيناريوهات

**الهدف:** بناء مصدر مشاهدات متكرر يمثل مشهد الحافلة والحجب.

**جدول العمل:** متغيرات المشهد؛ مخرجات كل حساس افتراضي؛ تسميات الحقيقة المرجعية؛ بذرة تكرار؛ إنشاء حالات فقد/تأخير.

**المخرج:** محاكي أولي يخرج بيانات اصطناعية حسب العقد ومجموعة سيناريوهات موثقة.

**معيار الإغلاق:** تشغيل السيناريو مرتين بنفس الإعداد يعطي النتائج المرجعية نفسها، ويمكن ضبط الحجب والتوقيت دون تعديل منطق الخطر.

**خارج النطاق:** فيديوهات حقيقية أو نماذج تدريب كبيرة.
