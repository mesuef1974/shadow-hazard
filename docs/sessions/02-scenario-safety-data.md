# جلسة 02 — مشهد الخطر والسلامة والبيانات

**الهدف:** تعريف حالات اختبار آمنة تغطي الحجب والبيانات غير الموثوقة.

**جدول العمل:** مواقع الحافلة والمشاة والمركبة في المحاكاة؛ زوايا الرصد؛ السرعة/المسافة الاصطناعيتان؛ فقد الرصد؛ تأخر البيانات؛ حالات الإنذار الخاطئ والفائت.

**المخرج:** مخطط مشاهد وجدول بيانات اصطناعية، سجل مخاطر محدث، وسياسة واضحة لما لا يصور ولا يخزن.

**معيار الإغلاق:** يوجد سيناريو أساسي وحالتان مضادتان على الأقل، وكلها قابلة للتكرار دون طريق أو شخص حقيقي.

**اعتماد المشرف:** ضروري قبل شراء عتاد أو جمع تصوير أو اختبار خارج المحاكاة.
