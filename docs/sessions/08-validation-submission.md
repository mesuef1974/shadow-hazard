# جلسة 08 — التقييم والتسليم

**الهدف:** تقييم الأدلة مقابل متطلبات المسابقة وتحضير حزمة مفهومة وصادقة.

**جدول العمل:** مصفوفة السيناريوهات؛ مقارنة حساس واحد/مصادر متعددة؛ أزمنة الإنذار؛ التنبيهات الكاذبة والفائتة؛ القيود؛ أجزاء التسليم الخمسة (بطاقة المشروع، PDF، ZIP، الفيديو، ثلاثة منشورات Instagram).

**المخرج:** تقرير نتائج مختصر، قائمة متطلبات مكتملة/ناقصة، خطة العرض، ومادة التسليم المتوافقة مع دليل القواعد المنشور.

**معيار الإغلاق:** كل ادعاء في الـPDF والفيديو والمنشورات مرتبط بمشهد/قياس ظاهر، وتذكر القيود بوضوح، ويراجع المشرف الحزمة.

**شرط سابق:** تُضبط طريقة التقييم ومتطلبات الملفات النهائية على أحدث دليل قواعد؛ لا تعتمدوا نصًا قديمًا من صفحة الأسئلة الشائعة عند التعارض.
