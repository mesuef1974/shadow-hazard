# تحسين واجهة الإدارة العربية

- تعريب التطبيقات والنماذج والحقول وتسميات الحالات، مع الحفاظ على أسماء الأعمدة والقيم المخزنة.
- أسماء مقروءة للسجلات والعلاقات، وأعمدة متخصصة وبحث ومرشحات لكل جدول سجل.
- معاينات ألوان مع رمز نصي، ومعاينات PNG/JPEG/WebP/SVG محمية بمصادقة المشرف.
- مسار المعاينة يقتصر على docs/brand، يتحقق من بصمة الملف وحجمه، ويعزل SVG بسياسة محتوى تمنع التشغيل النشط. لا عرض لملفات HTML أو الأسرار أو المسارات خارج المجلد.
- بقيت جداول السجل للقراءة فقط؛ صلاحيات الحسابات لم تتغير. لا اعتماد لأي اتجاه هوية.

## أدلة التحقق

نجحت 18 حالة اختبار للحسابات والسجل. تشمل فتح قوائم وتفاصيل جميع نماذج السجل، منع POST والتعديل والحذف، البحث والمرشحات، رفض المعاينات لغير المشرف ولمسارات غير مسموحة ولبصمة غير مطابقة.

أخذت نسخة SQLite محلية داخل backend/.local قبل الهجرات. مقارنة بصمات جميع صفوف accounts وregistry قبل الهجرات وبعدها متطابقة. أضيفت وقائع استخدام المهارات بعد المقارنة بصورة مقصودة.

تحقق المتصفح المدمج من البحث عن #6259D8 (نتيجة واحدة)، وتصفية خط الرؤية (ستة ألوان)، وتحميل الأصول الأربعة بما فيها SVG. صورة التحقق محلية مستثناة من Git: backend/.local/admin-arabic-proof.jpg.

تشغيل محلي على 8010؛ لم يحدث نشر أو دفع للمستودع البعيد. تبقى البيانات التقنية الأصلية مثل المسارات والمفاتيح وأوصاف الاستيراد دون ترجمة محتواها أو إعادة كتابتها.
