# توجيه المهام وسياقها

## الأنواع المنفذة

| النوع | التنفيذ | ما يُحمّل |
|---|---|---|
| تلقائي | حساب محلي للتعبير المحدد، وإلا نص خفيف | بحسب المسار الناتج |
| حساب مباشر | Python Decimal بلا نموذج | لا مهارات أو موصلات؛ تحفظ التعليمات والميثاق للتوثيق |
| نص أو سؤال | Codex بالنموذج المحدد في السياسة | ميثاق الجلسة وتعليمات المشروع والأساس الإلزامي لـCodex |
| برمجة | Codex | ما سبق + minimal-code-edit افتراضيًا + المهارات الإضافية المختارة |
| تصميم | Codex | ما سبق + frontend-design افتراضيًا + المهارات الإضافية المختارة |
| مهمة بموصل | Codex | الموصلات المسجلة المختارة فقط، والمهارات المختارة |

الحساب المحلي يقبل معاملين رقميين وعملية واحدة (+، -، *، /)، مع عبارة «احسب» اختياريًا. لا يستخدم eval ولا يقرأ ملفات مهمة ولا ينفذ أوامر. يقيد أحجام الأرقام، ويرفض القسمة على صفر. القسمة بدقة Decimal تبلغ 40 رقمًا. النصوص الأخرى لا تُختزل إلى تعبير حسابي بالبحث داخلها؛ مسار التوجيه التلقائي يعتمد المطابقة الكاملة فقط.

## حفظ التعليمات وسجل الاستخدام

جدول execution_context.TaskContext مرتبط بعلاقة OneToOne بطلب ModelJob. يحتفظ بنوع المهمة، المهارات والموصلات المحددة، تعليمات المشروع والجذور الأعلى وتعليمات المستخدم، نسخة الميثاق، محتوى المهارات المختارة، وبصمات الملفات. إذا تغير ملف تعليمات أو أضيف override بعد التفويض يتوقف الطلب القديم بدل استعمال سياق غير مسجل. لا تختصر تعليمات المشروع ولا تستبدل تعليمات Codex الأساسية.

لا تُحمّل الذاكرة العامة أو فهرس مهارات المضيف كاملًا. تدخل تعليمات المهارات المحددة كاملة من ملفاتها المسموحة، وتبقى مراجعها على القرص للقراءة عند الحاجة. الاختيار الحالي يدعم التعديل المحدود، الاختبارات المركزة، تصميم الواجهة، ومراجعة تجربة الاستخدام. لا يحذف اختيار مهارة إضافية المهارة الافتراضية لنوع المهمة.

تُعطل خوادم MCP العامة والإضافات غير المختارة في العملية الفرعية فقط. لا يعدل ذلك config.toml أو جلسات سطح المكتب. البحث عبر الويب يحتاج اختياره صراحةً. تعطيل الإضافات افتراضيًا تقليل للقدرات أيضًا؛ المهمة التي تحتاج خدمة تختارها قبل التفويض. جرى اختبار بناء الإعدادات واختيار الموصلات، ولم تنفذ مكالمات فعلية إلى حسابات خارجية.

تسجل المهارات المطلوبة عبر registry.record_usage عند بدء جلسة التنفيذ، مع بصمة ملف التعليمات والمهمة والجلسة والغرض وطريقة الإدراج. سجل الموصل يصف طلب تفعيله، وليس دليلًا على استدعائه. بصمته مرجع إعداد واضح وليست إصدار البرنامج الثنائي. تنفيذ الحاسبة له سجل خدمة فعلي وبصمة كوده ونتيجته. يحتفظ هذا الفصل بالفرق بين تحميل القدرة واستعمالها فعليًا.

## القياس والتحقق

- الطلب 10، من نموذج المنصة بوضع تلقائي: «احسب 17 + 25» → 42، بلا جلسة نموذج، وصفر إدخال وإخراج. سجل الاستخدام مؤكد بقاعدة البيانات.
- الطلب 9، المهمة النصية الأصلية نفسها على gpt-6-luna/low: 13517 إدخالًا و12 إخراجًا؛ مقابل 21468/12 أولًا و15973/12 بعد التخفيف السابق. رسالة AGENTS مطابقة للأصل والميثاق محفوظ. الانخفاض 37.0% من الإدخال الأصلي لهذه التجربة، وليس تقديرًا لتوفير حصة الاشتراك؛ التخزين المؤقت اختلف.
- الطلب 8 فشل قبل بدء نموذج بسبب صيغة مفاتيح إعدادات MCP؛ صُححت، ثم نجح فحص debug prompt-input دون نموذج واختبار الطلب 9. لا إعادة تلقائية للطلب الفاشل.
- 67 اختبارًا ناجحًا تشمل التوجيه، رفض الأكواد الحسابية، منع تكرار التفويض، الصلاحيات، حفظ السياق، تبدل التعليمات، المهارات الإضافية، حصر الموصلات، توثيق الاستخدام، واحتساب التوكنز.

بقي الأساس الإلزامي لـCodex؛ لا يدعي المسار النصي أنه منخفض التكلفة لكل سؤال صغير. يتجنب المسار المحلي استدعاءه للأعمال المحددة التي يستطيع الكود إنجازها. لا توجد فواتير API جديدة أو تثبيت خدمة نموذج أخرى ضمن هذا التغيير.
