# التصعيد المنضبط للنماذج

- كل مهمة جديدة تبدأ بلونا مع تفكير منخفض، والحسابات البسيطة تبقى محلية دون نموذج.
- يستطيع النموذج اقتراح التصعيد بسبب محدد، ويستطيع المشرف إنشاء اقتراح من المهمة المنتهية. الاقتراح ليس تصريحًا بالتنفيذ ولا يضمن اكتشاف كل مهمة صعبة.
- صفحة `/sessions/escalations/` تعرض السبب والنموذج المقترح والمهمة والميثاق والصلاحيات والمهارات والموصلات واستهلاك المحاولة الأصلية.
- المشرف وحده يوافق أو يرفض. الموافقة تنشئ محاولة واحدة مرتبطة بالسياق المحفوظ؛ تكرار الطلب لا يكرر التشغيل. الرفض نهائي لذلك الاقتراح.
- لا تغيّر الموافقة نموذج المحادثة المفتوحة أو الافتراضي. تغيير محتوى المهمة أو سياقها يمنع استعمال الموافقة. المهام القديمة دون سياق مثبت تحتاج مهمة جديدة بلونا.
- يحفظ جدول EscalationRequest المصدر والسبب والوقت وصاحب القرار وملاحظته ولقطة السياق والاستهلاك ورابط المحاولة المعتمدة. تعرض المحاولات استهلاكها الفعلي؛ المخزن مؤقتًا جزء من الإدخال ولا يضاف مرة ثانية.
- لا يوجد تقدير مصطنع لاستهلاك المحاولة الأعلى. يظل غير معلوم حتى ورود القراءة الفعلية. لا إعادة تلقائية للتنفيذ غير المحسوم.
- التحقق: اختبارات للرفض والصلاحيات وCSRF وثبات السياق ومنع التنفيذ غير المعتمد وتكرار الموافقة وجمع الاستهلاك؛ التنفيذ الأعلى محاكاة دون استهلاك فعلي.
