# سجل مواصفات وقياسات العتاد

يوثق `HardwareSnapshot` وقت القراءة ومصادرها، وتخزن `HardwareRecord` كل خاصية منفردة مع نوعها ومصدرها وحالة موثوقيتها. `specification` للمواصفات الثابتة التي يعلنها النظام، و`measurement` لقراءات لحظية تتغير مع الاستخدام. لكل قيمة مصدر مستقل، وكل لقطة تستخدم وقت UTC.

تدخل اللقطات عبر `record_hardware_snapshot ENVELOPE.json`. الظرف يقبل قائمة حقول محددة فقط، فيرفض أي حقل معرف إضافي. لا تخزن أرقامًا تسلسلية أو عناوين MAC أو اسم الجهاز أو حساب Windows أو معرفات العتاد. قيم VRAM والسعات المشتركة/المشتقة يجب تمييزها `estimated` مع شرح أساس التقدير؛ لا تعامل AdapterRAM الخاص بالرسوميات المدمجة على أنه VRAM مخصصة.

## حدود القراءة الأولى

اللقطة الأولية تصف محطة التطوير المحلية كما قرأها Windows في 2026-10-31. لا تمثل عتادًا اختاره الفريق للنموذج، ولا اعتمادًا للتشغيل على طريق أو موقع مدرسي. قراءات نسبة CPU والذاكرة الحرة وذاكرة GPU الحرة ومساحة القرص آنية وتقريبية بطبيعتها، ولا يصح تعميمها كأداء مستمر.

واجهة Django Admin للقطات والقيم قراءة فقط؛ اللقطات التاريخية لا تعدل من الواجهة. إنشاء لقطة لاحقة يتم بظرف جديد ذي معرّف ووقت ومصادر موثقة.
