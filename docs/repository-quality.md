# جودة المستودع ودورة التسليم

المستودع عام بقرار صريح من سفيان في 31 أكتوبر 2026. قاعدة التشغيل والأسرار وملفات `.local` تبقى خارج Git. العمل على فرع مستقل، ثم Pull Request إلى `main`؛ لا دمج تلقائي ولا دفع مباشر إلى `main`.

## بوابات الفحص

- `Repository hygiene`: منع تتبع ملفات التشغيل الخاصة وقاعدة البيانات، فحص أنماط محددة للأسرار دون طباعة قيمها، مطابقة بصمات الهوية المعتمدة، والتأكد من تثبيت Actions ببصمة commit كاملة. ليس بديلًا عن تدقيق أمني شامل.
- `Backend / sqlite` و`Backend / postgres`: فحص Django والهجرات، تطبيقها على قاعدة اختبار، الاختبارات، وتجميع الملفات الثابتة. قاعدة PostgreSQL وحسابها مؤقتان داخل CI.
- `Report browser`: اختبار أحجام 320/390/768/1440، القائمة والروابط المباشرة، البحث، اكتمال PDF بعد البحث أو الطي واستعادة الحالة.
- `Dependency audit`: التحقق من الثغرات المنشورة لاعتماديات التطبيق وأدوات فحص التقرير باستخدام pip-audit؛ أي ثغرة أو تعذر تدقيق يجعل الفحص يفشل، دون استثناءات صامتة.

صلاحيات CI هي القراءة فقط، ولا يحتفظ checkout ببيانات الاعتماد. حد زمني لكل مهمة مع إلغاء التشغيل المتكرر للفرع نفسه. لا أسرار إنتاج ولا نشر Railway داخل هذا المسار. تحديثات Dependabot أسبوعية وتبقى طلبات مراجعة.

## حماية main المطلوبة

نجاح البوابات الخمس، تحديث الفرع مع main، مراجعة واحدة على الأقل، إلغاء الاعتمادات القديمة عند تغيير الكود، حسم المناقشات، منع force push والحذف، وتطبيق القواعد على المسؤولين. مراجعة صاحب PR لنفسه غير مقبولة. `CODEOWNERS` يحدد صاحب المشروع؛ يلزم مراجع GitHub آخر مؤهل عندما يكون صاحب المشروع هو مؤلف الطلب.

إعدادات الحماية تُتحقق عبر GitHub بعد تطبيقها؛ وجود هذه الوثيقة وحده ليس دليلًا على تفعيلها. لا تغيّر خصوصية المستودع أو خطة الحساب لتجاوز قيود GitHub.

## إعادة الفحص محليًا

```powershell
.\.venv\Scripts\python.exe backend/manage.py check --fail-level WARNING
.\.venv\Scripts\python.exe backend/manage.py makemigrations --check --dry-run
.\.venv\Scripts\python.exe backend/manage.py test accounts registry --noinput
python tools/ci/check_repository.py
# في بيئة تحتوي اعتماديات tools/ci/requirements.txt ومتصفح Playwright:
python tools/ci/check_report.py
```

يمكن ضبط `REPORT_BROWSER_CHANNEL=msedge` للاستفادة من Edge المثبت محليًا. CI يستخدم Chromium مثبتًا في بيئته المؤقتة. لا تنقل قاعدة `.local` إلى GitHub؛ لها نسخ احتياطية مستقلة. تقرير المراجعة البصرية السابقة يخص بصماته المسجلة، ولا يغني عن فحص التغييرات اللاحقة.
