# السلامة والخصوصية

## حدود السلامة

- النموذج تنبيه مساعد في محاكاة تعليمية، وليس منتج سلامة أو نظام تحكم مروري.
- لا تنفذوا اختبارًا على شارع أو موقف فعلي أو مع مركبة متحركة. استخدموا مجسمات/فيديو اصطناعيًا وسيناريو مضبوطًا.
- لا تعرضوا صوتًا أو ضوءًا يمكن أن يشتت مستخدم طريق حقيقي؛ محاكاة العرض فقط.
- عند فقد حساس أو تقادم البيانات أو تعارض الرصد، الحالة `DEGRADED` أو `UNKNOWN`، لا إعلان أن الطريق خالٍ.
- ينبغي للمشرف مراجعة التجربة والعرض قبل تشغيل أي جهاز أو تصوير أي مشارك.

## الخصوصية والبيانات

- الافتراضي بيانات اصطناعية أو مشاهد مجسمات بلا أشخاص قابلين للتعرف.
- لا تجمعوا وجوهًا أو لوحات مركبات أو مواقع دقيقة أو صوتًا من مدرسة دون موافقات واضحة من الجهة والأشخاص المعنيين وإشراف المشرف.
- عند اضطرار بحثي لاحق لجمع تصوير، توثق الغاية، الموافقات، من يصل للملفات، مكانها، مدة الاحتفاظ، وآلية الحذف قبل التسجيل.
- لا ترفعوا بيانات خامًا أو وثائق شخصية أو مفاتيح وصول إلى GitHub أو أدوات عامة.
- احتفظوا بأقل بيانات تكفي لحساب المؤشرات؛ استبدلوا الهويات بمعرفات تجريبية واحذفوا الملفات الخام عند انتهاء الحاجة المعتمدة.

## سجل المخاطر المبدئي

| الخطر | الأثر | المعالجة الأولية |
|---|---|---|
| بيانات متقادمة أو غير متزامنة | تنبيه متأخر أو خاطئ | توقيت UTC، قياس العمر، وإظهار حالة التدهور |
| اختلاف المعايرة بين المصادر | تقدير مكاني مضلل | لا دمج مكاني قبل توثيق المعايرة والوحدات |
| إنذار كاذب أو عدم اكتشاف | ثقة زائفة بالعرض | عرض الحدود، وقياس الحالتين على سيناريوهات اصطناعية |
| تصوير أشخاص/لوحات | كشف بيانات شخصية | تجنب التصوير الحقيقي وافتراضية المحاكاة |
| تجربة قرب حركة فعلية | أذى مادي | حصر العرض في طاولة/محاكاة وإشراف بالغ |
