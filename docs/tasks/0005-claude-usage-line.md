# مهمة 0005: سطر كلفة Claude من سجلات Claude Code المحلية

- الهدف: `scripts/claude_usage.py` يحسب توكنز Claude Code لهذا المشروع بصفر توكنز، فيحل محل الإدخال اليدوي في سطر الكلفة (قرار المشرف 2026-11-04).
- المصدر: ملفات JSONL تحت `%USERPROFILE%\.claude\projects` (أو `CLAUDE_CONFIG_DIR`) مع ملفات الوكلاء الفرعيين؛ تُختار الأسطر التي `cwd` فيها داخل جذر المستودع بمقارنة مسار مُطبَّعة.
- الحساب: حذف التكرار بمعرّف الرسالة (`message.id`)؛ الطازج = `input_tokens` + `cache_creation_input_tokens` + `output_tokens`، والمخزَّن = `cache_read_input_tokens`؛ تجميع لكل يوم وجلسة وفرع (`gitBranch`) ونموذج، ورقم المهمة من اسم الفرع.
- الخرج: JSON وسطر عربي واحد؛ أرقام وتواريخ وفروع ونماذج فقط، ولا نص من المحادثات. مجلد غائب أو صيغة مجهولة ← «غير متاح» لا صفر. يسجّل حدث `usage` عبر `automation_events.record`.
- القبول: `scripts/test_claude_usage.py` على عينة ثابتة: رسالة مكررة تُحسب مرة؛ `cwd` خارج المستودع مستبعد؛ ملف وكيل فرعي محسوب؛ لا حقل نصي في الخرج؛ «غير متاح» عند الغياب. أقل من 5 ث على شهر من السجلات. مطابقة جلسة محلية لسطر «Usage by model» في `/usage` قبل `/clear`. `prepush_check` ينجح.
- خارج النطاق: قاعدة المنصة و`backend/` كله؛ أي مهمة مجدولة؛ الجلسات السحابية والشات (يوسمان «غير متاح محليًا»، وحصة المقعد سطر يدوي).
- المرجع: ADR 0003 (المبدأ والطبقة 2)، وتقرير «خطة تعديل المنصة واحتساب التوكنز» قسم «3. احتساب التوكنز». لا تقرأ غيرهما.
- الإنهاء: ثلاثة أسطر تحت «حالة الكود» في ملف التسليم.
- الحالة: معلّقة بقرار الجلسة الواحدة 2026-11-04 (ADR 0002): لا جلسات Claude Code محلية تُقاس، فسطر الكلفة يبقى سطر حصة المقعد اليدوي.
