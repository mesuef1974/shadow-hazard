# مراجعة مستقلة لتطبيق الهوية على تقرير مخطط المشروع

**الحكم: اجتاز نطاق المراجعة بعد الإصلاحات.** لا توجد ملاحظات مفتوحة عالية أو متوسطة الأولوية ضمن الفحوص المنفذة أدناه. هذا الحكم يخص التقرير المحلي، وليس اعتمادًا للمنصة المستقبلية أو تصريحًا بالنشر.

المراجع: `report_design_review`، مستقل عن منفذ تعديلات الواجهة. تاريخ المراجعة: **31 أكتوبر 2026 — Asia/Qatar**. لم يعدّل المراجع ملفات الإنتاج؛ اقتصرت ملكيته الكتابية على هذه الوثيقة وأدلة الفحص المحلية.

## المنهج والمرجع

- **web-design-guidelines:** جلب النسخة الحالية من [Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md)، ومراجعة الدلالات والتنقل والتركيز والحالات والتجاوب.
- **ui-ux-pro-max:** تطبيق نتائج البحث المحلية ذات الصلة بمعالجة الجداول على الهاتف وحالات البحث بلا نتائج، ومراجعة الاتساق مع الهوية المعتمدة وأهداف اللمس.
- **accessibility:** فحص الأسماء والدلالات والوصول بلوحة المفاتيح وحالات التفاعل بصريًا ومن خلال DOM. لم تتوفر أداة Lighthouse في الجلسة أو أمر مثبت، ولم تُثبّت اعتماديات إضافية. النتيجة ليست شهادة امتثال WCAG شاملة أو اختبارًا بقارئ شاشة فعلي.

المرجع البصري: هوية `reveal-occlusion`، الإصدار 1.0، من `docs/brand/approved-v1/`. الملفات المفحوصة: `review-ar.html` و`report-brand.css` و`report.js`. المتصفح: Microsoft Edge الحقيقي عبر Playwright، مع صور شاشة وملفات PDF فعلية.

## الملاحظات الأصلية ونتيجة إعادة الفحص

| الأولوية | الملاحظة المثبتة قبل الإصلاح | نتيجة التحقق بعد الإصلاح |
|---|---|---|
| عالية | الطباعة بعد بحث بلا نتائج أو طي الأقسام تختزل التقرير من 13 إلى 9 صفحات وتسقط جداول مثل `SensorInstallation`. | الطباعة في الحالتين تنتج 13 صفحة وتضم `SensorInstallation` و`ExhibitionRelease`؛ البحث وحالة الطي يستعادان بعدها. |
| متوسطة | خطوط وأسهم SVG تستخدم اللون القديم `#a26b1f` خارج الهوية. | لا عناصر SVG باللون القديم؛ الخطوط والأسهم مرتبطة بالبترولي المركزي، والنصوص والخلفيات بهوية المشروع. |
| متوسطة | البحث بلا نتائج يخفي 67 صفًا دون تفسير أو إرشاد أو إعلان حالة. | رسالة واضحة وإرشاد للمسح، وعدّاد نتائج معلن، وأزرار مسح وفتح وطي. |
| متوسطة | مناطق التمرير الأفقي لا توضّح للمستخدم وجود محتوى جانبي ولا تملك أسماء وصول صريحة. | عشر مناطق معرفة وقابلة للتركيز، مع إرشادات التمرير باللمس أو لوحة المفاتيح. |
| منخفضة | غياب رابط تجاوز الغلاف، وارتفاع أهداف التنقل نحو 42.59 بكسل. | رابط تجاوز إلى المحتوى، وقياس أهداف التنقل والأزرار 46 بكسل، مع حالات تركيز واضحة. 44 بكسل توصية المهارة وليست هنا ادعاء خرق WCAG AA. |
| منخفضة | CSS قديم مضمّن تصححه طبقة تجاوز لاحقة، مما أبقى بعض الألوان القديمة. | أزيلت الطبقة المضمّنة القديمة؛ تنسيق التقرير موحد في ملف يعتمد رموز الهوية المركزية. |

رصدت إعادة الفحص تجاوزًا أفقيًا ناتجًا عن نصوص وروابط طويلة، وأعداد مجموعات مضللة في الطباعة بعد التصفية. أصلح الأول بكسر النصوص الطويلة، والثاني بإخفاء عدادات نتائج البحث في الطباعة. أُعيد التحقق من الإصلاحين استقلاليًا.

## الفحوص الناجحة

- أبعاد العرض **1440 و768 و390 و320 بكسل**: عرض الوثيقة يساوي عرض النافذة؛ لا تمرير أفقي على مستوى الصفحة. تبقى الجداول والمخطط قابلين للتمرير داخل مناطقهما المخصصة.
- فحص بصري للغلاف على الهاتف، ولمخطط العلاقات على الحاسوب، ولعينة من صفحات الطباعة. الشعار والتميمة والخطوط المحلية تظهر دون موارد مفقودة.
- ألوان المخطط مرتبطة بالرموز المعتمدة؛ لا تسرب للذهبي القديم. التمييز بين رأس الجدول والصفوف ومجموعات القاموس وحالات التفاعل مستمد من الهوية نفسها.
- البحث بلا نتائج يعرض تفسيرًا وعدّادًا؛ المسح يعيد المحتوى، والفتح والطي يعملان. منطقة الرسم لها `role="img"` وعنوان مرتبط؛ البحث له تسمية ظاهرة.
- طباعة القاموس كاملة رغم البحث أو الطي، واستعادة الحالة بعدها، وإخفاء العدادات المرتبطة بنتائج الشاشة في الطباعة فقط.
- **صفر أخطاء JavaScript** مرصودة أثناء السيناريوهات المختبرة.

## أدلة المراجعة

الأدلة محلية وغير مرفوعة إلى Git، تحت `backend/.local/review-independent/`:

- `review-ar.md` و`audit.json`: خط الأساس والملاحظات الأصلية.
- `print.pdf` و`print-no-results.pdf` و`print-collapsed.pdf`: إثبات نقص الطباعة قبل الإصلاح.
- `recheck/audit.json` و`recheck/print-filtered.pdf` و`recheck/print-collapsed.pdf`: إعادة الفحص الوظيفي واستعادة الحالة.
- `recheck/final-checks.json`: قياسات الأحجام الأربعة وإخفاء العدادات في الطباعة وبصمات الملفات المفحوصة.
- `recheck/mobile-320-final.png` و`recheck/diagram-final.png`: أدلة بصرية نهائية.

أعيد الفحص بعد تنسيق ملف CSS وتحسين إطار تركيز رابط التذييل؛ ظلّت الأحجام الأربعة سليمة، والعدادات مخفية في الطباعة. أثبت اختبار لوحة المفاتيح إطارًا كهرمانيًا بعرض 3 بكسل حول رابط التذييل (`recheck/footer-focus.json` و`footer-focus-final.png`). بصمة CSS النهائية المفحوصة: `33e45002f827334a1d1ed43151fb1e80ef029fc48eec91f9d31b7ad0b0bb4d8c`، وبقية بصمات النسخة محفوظة في `final-checks.json`.

## حدود الحكم

المراجعة تغطي تطبيق الهوية والتفاعل والتجاوب والطباعة في التقرير المحدد. لم تشمل اختبار متصفحات أخرى أو قارئ شاشة فعلي أو تدقيقًا قانونيًا لمحتوى المشروع أو قياسًا شاملًا لكل معايير WCAG. لا تمنح درجة رقمية انطباعية، ولا تحوّل محتوى الوثيقة الموصوف بأنه «للمراجعة» إلى قرارات معتمدة.
