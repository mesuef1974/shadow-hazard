نقل صلاحية الاتصال بأثر محفوظ

الصلاحية تربط العامل بهوية جلسة داخل التطبيق. نقلها يحفظ مواثيق جلسات العمل وتاريخها.

  1. تفويض ولقطة قبل النقل

    مصدر وهدف مسجلان، وبصمات الاتصال وسياسات التجديد والمتابعة ونسخة احتياطية.

  2. تجميد الإرسال والتحقق

    حجز واحد للعملية، وفحص خمول المصدر والهدف من التطبيق والسجل الأصلي.

  3. تبديل مشروط ثم تحقق

    مقارنة البصمات قبل التبديل، وتحديث مراجع الموافقات والتحقق من الاتصال الجديد.

  4. استعادة العملية نفسها

    إذا انقطع التنفيذ يُستكمل الجورنال نفسه من الدليل. اختلاف الحالة يعزل العملية للمراجعة دون نقل أو إرسال مكرر.

حامل الاتصال لا يجدد نفسه. جلسات العمل تُجدد بعد الخمول وفق اعتمادها؛ تجديد حامل الاتصال يتطلب نقل صلاحية مأذونًا أولًا. الإشعار الذاتي للمشغّل مقيد بتفويض ودليل تسليم رسمي متحقق.

ما الذي يدخل إلى سياق المهمة؟

مصدر واضح لكل نوع من التعليمات. لا ننسخ تاريخ الجلسات أو كتالوج الأدوات إلى كل طلب.

قياس السياق: تنبيه 70٪ وتجهيز 85٪

الإجراءات تعتمد مصدر قياس حديثًا ومتحققًا؛ الأرقام الأسبوعية أو الإجماليات التراكمية لا تحدد إشغال السياق.

  1. قراءة موثوقة وحديثة

    ربط القياس بالجلسة والنموذج ومصدره، مع التحقق من توقيت العينة ودلالة الحقول.

  2. عند 70٪: تنبيه

    تنبيه موثق مع منع تكراره ضمن دورة العتبة نفسها.

  3. عند 85٪: طلب محفوظ

    يُحفظ طلب التسليم والتجديد في القاعدة، ويبقى محفوظًا بعد ضغط السياق.

  4. التحقق قبل التنفيذ

    تقادم البيانات أو تضاربها يمنع التنفيذ. الطلب ينتظر الخمول والتفويض وسلامة المسار.

تجديد تلقائي وفق سياسة معتمدة

السياسات المعتمدة تشمل ظل الخطر والباك إند والواجهة والمراجعة؛ راجع متابعة الاستهلاك للحالة الفعلية الحالية.

  1. تثبيت طلب 85٪

    طلب دائم واحد لكل مصدر؛ انخفاض القياس بعد الضغط لا يمحو الطلب المحفوظ.

  2. حفظ تسليم محدود

    الميثاق والقرارات والأعمال المتبقية ومراجعها في القاعدة؛ تحميل التفاصيل عند الحاجة.

  3. انتظار الخمول

    التحقق من التطبيق والسجل وغياب العمل الجاري أو التسليم الملتبس قبل الإنشاء.

  4. تحقق البديلة وربطها

    مسار التجديد نفسه يتحقق من التسليم والنموذج والدليل قبل تحديث ربط الميثاق.

تُحفظ الجلسة السابقة وتاريخها؛ لا أرشفة تلقائية أو إعادة إرسال للمهام القديمة. إذا التبس إنشاء البديلة يُفحص الدليل وتُستعاد العملية المسجلة دون إنشاء آخر عشوائي.

من نتيجة المهمة إلى الدمج والنشر

مسار الإصدار المطلوب للتغييرات البرمجية الجاهزة. اكتمال المهمة وحده لا يدمج الكود ولا ينشره.

غير مؤتمت حاليًا: هذا مسار موضح للاعتماد والتنفيذ؛ لا توجد هنا أزرار تنفيذ أو ربط للنشر بالموزّع. نشر Railway يحتاج طلبًا صريحًا من سفيان. يمكن النشر مباشرة دون مستودع بعيد.

  1. تجهيز نسخة قابلة للمراجعة

    فرق التغييرات ونطاقها والملفات المقصودة فقط؛ تثبيت مرجع Git للنسخة دون ضم عمل الجلسات الأخرى.

  2. اختبارات ومراجعة مستقلة

    اختبارات مناسبة للتغيير وفحص الواجهة والصلاحيات والأمن؛ يسجل المراجع النتيجة مقابل النسخة المحددة.

  3. بوابة قبول الإصدار

    تكتمل الأدلة وتُحسم العوائق المانعة؛ تغيّر الكود بعد المراجعة يستلزم تحققًا جديدًا يناسب التغيير.

  4. الدمج المحلي

    دمج النسخة المقبولة إلى main ضمن التفويض، وحفظ مرجع الدمج. نجاح مهمة الجلسة لا يُعد إذنًا بالدمج أو الدفع البعيد.

  5. اعتماد النشر

    سفيان يحدد النسخة والبيئة ويأذن بالنشر؛ يبقى الإصدار جاهزًا محليًا حتى وصول الطلب.

  6. نسخة احتياطية وهجرات

    نسخة احتياطية متحققة وخطة استعادة مناسبة لقاعدة بيئة النشر، وفحص الهجرات والمتغيرات دون كشف الأسرار.

  7. نشر مباشر إلى Railway

    نشر النسخة المعتمدة، وتسجيل معرف النشر ومرجع الكود. يلزم توصيل هذه الخطوة بأداة النشر قبل اعتبارها آلية.

  8. فحص التشغيل والإغلاق

    اختبار الصحة والصفحات والبيانات والسجلات بعد النشر؛ حفظ إيصال النتيجة. نجاح البناء وحده لا يثبت نجاح الإصدار.

عند فشل فحص التشغيل: يُوقف اعتماد الإصدار وتُنفذ خطة التراجع المصرّح بها إلى نسخة معروفة. تراجع الكود لا يعكس هجرات البيانات تلقائيًا؛ استعادة البيانات إجراء منفصل محكوم بخطة وموافقة.

سجل الإصدار المطلوب: المهمة، مرجع الكود، نتيجة الاختبارات، المراجع، قرار الدمج، موافقة النشر، النسخة الاحتياطية، معرف نشر Railway، فحوص التشغيل وأي تراجع. هذه الروابط ليست دورة إصدار آلية منفذة بعد.

تعرض الصفحة المسار الموجود في الكود. نجاح النقل لا يثبت صحة التنفيذ، وتجهيز السياق لا يضمن مقدارًا ثابتًا من التوفير.

ما تغير إرسال الجلسات يمر عبر مدخل واحد إلى تطبيق المالك؛ لا ناقل احتياطي خفي. يحمل المشغّل الاتصال، وتُحفظ عمليات النقل والتجديد والاستعادة في القاعدة. تحليل النموذج يُطلب عند استثناء قابل للعمل فقط.

المسارات المساندة الحساب المحلي والقراءة المعزولة منفصلان عن إرسال محادثات التطبيق. تجربة العامل الخفيف ليست بديلًا عامًا معتمدًا لربط الجلسات.

التحقق التشغيلي راجع صفحات الجلسات والمهام والاستهلاك لمعرفة الحالة الحالية. الاتصال بهوية التطبيق وتجديد قناته لا يمنحان إذنًا بنشر أو حذف أو تثبيت؛ تغيير نسخة التطبيق يحتاج إعادة اعتماد الثقة.
