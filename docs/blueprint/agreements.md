# مخطط المشروع والمنصة — وثيقة القرار

تاريخ الإعداد: 30 أكتوبر 2026. الحالة: **تصميم للمراجعة قبل البرمجة**. لا تمثل هذه الوثيقة وظائف منفذة أو موافقة على شراء أو نشر.

## الاتفاقات المؤكدة
- المشروع «ظل الخطر»: نموذج مصغر يعمل لاكتشاف خطر مروري محجوب، يبدأ بمشهد حافلة تحجب مشاة عن مركبة قادمة؛ مقارنة الرصد المفرد والمتعدد وحداثة البيانات.
- سفيان صاحب الفكرة والمشرف والقائد التقني، والطالبان سعود ومبارك. نثبت ذلك كتاريخ للمشروع، ولا نستنتج منه وحده التحديد القانوني للمخترعين أو ملكية الحقوق.
- ثلاثة حسابات فقط؛ سفيان ينشئ المهام ويعيد الإسناد ويعتمد النتائج، والطالبان ينفذان ويحدثان. تسجيل ساعات العمل اختياري.
- التواصل بتعليقات وإعلانات؛ توثيق الجلسات ومحاضرها والمهام، والمواد والمعدات منذ البداية. توسع النطاق اللاحق ليشمل التكلفة والمشتريات.
- Django خلفية علائقية مرنة؛ PostgreSQL هو اقتراح قاعدة البيانات؛ Railway وجهة النشر المطلوبة لاحقًا.
- المنصة منتج تكاملي يعرض في المسابقة: مساحة فريق خاصة، غرفة تشغيل النموذج، وعرض تحكيم تفاعلي.
- توثيق كامل من الفكرة والدراسة القبلية إلى التصميم والبناء والتجارب والنموذج النهائي، ثم الصيانة والتطوير.
- حفظ التاريخ والمساهمات والإصدارات والأفكار والعوائق والقرارات والأدلة والحقوق والإفصاحات.
- هذا الطلب لإعداد الوثائق والمخطط والخطة وعرضها؛ يبدأ تنفيذ البرمجيات بعد مراجعة المالك.

## المقترحات المعمارية
- تطبيق Django معياري واحد، ووحدات داخلية محددة؛ خدمات مستقلة فقط عند وجود حاجة مثبتة. نواة التحليل الطرفية للمجسم مستقلة عن إدارة المشروع.
- Git مرجع الكود؛ ملفات وأوزان ووسائط في تخزين خاص، وقاعدة البيانات مرجع العلاقات والنسخ والموافقات. مزود التخزين لم يعتمد بعد.
- ثلاث واجهات في نظام واحد. إطار الفرونت إند ومكتبة المجسمات لم يحددا؛ نختارهما بعد نموذج واجهة ومقارنة تكلفة التطوير والأداء.
- المشهد ثنائي الأبعاد أولًا، ثم ثلاثي الأبعاد، ثم ربط بالقياسات. «توأم رقمي» وصف مشروط بربط ومعايرة يمكن التحقق منهما.
- لا يعتمد إنذار المجسم على زمن اتصال Railway أو مساعد لغوي. المعالجة اللازمة للإنذار محلية؛ ترسل المنصة الأحداث والنتائج للعرض والتوثيق.
- القياس والمحاكاة وإعادة التشغيل أوضاع صريحة، تحمل وقت الرصد والاستلام والمصدر وحالة الاتصال. توقف تدفق البيانات يظهر كتوقف، لا مشهد آمن.
- الذكاء المساعد متدرج: فحص نقص الأدلة وقواعد تحليل النتائج أولًا؛ مساعد معرفي بمصادر ومسودات تحتاج مراجعة لاحقًا.

## النطاق الأول وشروط النجاح
نموذج مصغر على طاولة/بيئة مضبوطة؛ تعريف أبعاد المشهد والحجب ومسارات الأجسام ومعايرتها قبل اختيار العتاد. لا تعمم نتائج مقياس مصغر على مسافات وسرعات الطريق الحقيقي دون تحليل مستقل.
- دليل مقارنة مع مصدر واحد، ومصادر متعددة، ومصادر متعددة مع فحص الحداثة والثقة.
- قياس زمن الإنذار، الإنذارات الخاطئة، الحالات الفائتة، التأخر، وحالات فشل مصدر. تعريف المقامات والمرجع الزمني وشروط القياس قبل جمع النتائج.
- فصل بيانات التدريب والضبط والتقييم على مستوى المشهد/التسجيل لتقليل تسرب البيانات؛ تثبيت بذور المحاكاة وإعداداتها.
- تدريب نموذج من الصفر خيار بحثي يبرر بمقارنة وأثر وجدوى، وليس شرطًا مسبقًا. لا اختيار مؤكد لأجهزة أو مكتبات أو أوزان حتى الآن.
- نسخة نهائية قابلة لإعادة التشغيل، مع قائمة مكونات وكود ومعايرة وأوزان وتجارب وأدلة محددة.

## الصلاحيات المقترحة للتفصيل
| الفعل | سفيان | سعود ومبارك |
|---|---|---|
| الحسابات والأدوار والخطط والإسناد | إدارة | عرض |
| تحديث المهام | جميع المهام | المهام المسندة إليهما |
| محضر وتحديث وتعليق ومسودة تسليم | إنشاء ومراجعة | إنشاء مسودة ومساهمة منسوبة لصاحبها |
| قبول تسليم أو مرحلة أو تغيير خطة | اعتماد | طلب مراجعة |
| فكرة أو عائق أو احتياج مواد | إنشاء واعتماد | تقديم مقترح |
| شراء وتعديل ميزانية | اعتماد | تسجيل احتياج/استلام بإذن |
| ملفات حقوق وإفصاح حساس | إدارة | حسب إتاحة صريحة |
| نشر مادة العرض | اعتماد إصدار منقح | إعداد مسودة |

المصادقة وحدها لا تكفي: تحقق صلاحية على الخادم لكل عملية وملف. لا روابط تخزين عامة افتراضيًا. يحذف نهائيًا فقط وفق سياسة احتفاظ معتمدة، وتؤرشف السجلات الهندسية المقبولة. كلمات المرور لا تسجل في الملفات أو Git.

## خط التاريخ
كل قرار أو إصدار مقبول يحتفظ بتاريخ الإنشاء والفاعل ومرجعه وسبب التغيير. لا تعدل نسخة معتمدة بصمت؛ تنشأ مراجعة جديدة وتربط بالسابقة. سجل التدقيق لا يستنسخ كلمات السر والرموز والملفات الحساسة. سجل المساهمات منفصل عن سجل استخدام الحساب.

## الدراسة القبلية والحقوق
- دراسة السوق: المستفيد، البدائل التجارية، آلية العمل، البيئة والتكلفة ومصدر السعر وتاريخه والقيود. «غير معلوم» قيمة صحيحة، وليس ضعفًا مثبتًا للمنافس.
- دراسة تقنية: الأبحاث والبراءات المنشورة والحلول المفتوحة، مع المصدر والمؤلف والتاريخ وملخص الدليل ودرجة صلته.
- فرضيات التميز لا تعرض كحقائق قبل تجربة مقارنة. بحث الجدة يختلف عن دراسة حرية الاستغلال القانوني.
- وثق المعرفة السابقة للمشروع، المساهمات الجديدة، تراخيص البيانات/الأوزان/المكتبات، الموافقات والاتفاقات، والإفصاحات ومواعيد إجراءات الحماية.
- الإفصاح قبل الإيداع قد يؤثر على الجدة؛ لا تفترض فترة سماح. تراجع سياسة المدرسة والجهة وشروط المسابقة مع مختص قبل نشر تفاصيل تمكّن إعادة التنفيذ أو تحديد ملكية/طلب براءة.
- المستودع الخاص والسجل المؤرخ أدلة تنظيمية، وليسا منحًا لحقوق براءة. لا يوجد تقييم جدة أو طلب براءة منفذ حاليًا.

## قرارات مفتوحة قبل التنفيذ المعني
1. وقت الفريق الأسبوعي والميزانية والعتاد المتوفر فعلًا، وأبعاد المجسم وطريقة تحريك عناصره.
2. تعريف مؤشرات القبول والحدود التجريبية وخطة التقييم.
3. وسيلة دخول الحسابات الثلاثة واستعادة الوصول، دون إنشاء حساب رابع.
4. مزود الملفات الخاصة، مدة الاحتفاظ، سياسة الاستعادة، وأهداف فقد البيانات/مدة التوقف المقبولة.
5. الفرونت إند والمكتبة ثلاثية الأبعاد وبروتوكول الحساسات بعد مقارنة خيارات.
6. العرض عبر حساب المشرف مبدئيًا؛ المشاركة العامة أو حسابات للجنة غير معتمدة.
7. حقوق الاستخدام والملكية والإفصاح بعد مراجعة الجهة. لا اختيار قانوني نهائي في هذا التصميم.
