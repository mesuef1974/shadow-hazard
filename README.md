# ظل الخطر

نموذج أولي لمسابقة تحدي علوم المستقبل: استكشاف إنذار مبكر لمخاطر المشاة والمركبات التي تحجبها عوائق مثل الحافلات المدرسية.

## الفكرة

يدمج المشروع رصدًا من أكثر من زاوية، ويحلل حركة المشاة والمركبات واتجاهاتها وحداثة القياسات لتقدير احتمال تقاطع المسارات. النموذج الأولي يركز على مشهد محاكاة لحافلة تحجب مشاة عن سيارة قادمة، ويقارن جدوى الرصد التعاوني مع كاميرا واحدة.

> هذا مشروع تعليمي تجريبي. لا يستخدم للتحكم المروري أو لاتخاذ قرار سلامة حقيقي.

## الحالة

المستودع في مرحلة تأسيس المتطلبات والمعمارية. لا توجد بعد أجهزة معتمدة أو بيانات تدريب أو خوارزمية كشف مختارة. القرارات المؤثرة تسجل في `docs/decisions/`.

## بنية المصدر

```text
src/shadow_hazard/
  domain/        نماذج المجال وقواعد الخطر المستقلة
  application/   حالات الاستخدام وتدفق تحليل المشهد
  ports/         عقود الحساسات والساعة والتنبيه والتخزين
  adapters/      المحاكاة والكاميرا والحساسات والمخرجات
  safety/        حداثة البيانات والثقة والسلوك الآمن عند الفشل
```

## البدء

يتطلب Python 3.12 أو أحدث. لا توجد حاليًا تبعيات تشغيلية خارج المكتبة القياسية.

```powershell
py -3.12 -m venv .venv
& .\.venv\Scripts\Activate.ps1
python --version
```

يجري اعتماد أوامر التشغيل ومزود الرؤية بعد قرار معماري موثق. لا تثبّت حزمًا أو تنزّل نماذج قبل موافقة المشرف وتسجيلها في `pyproject.toml`.

## الجودة والتعاون

- اقرأ `AGENTS.md` و`CONTRIBUTING.md` قبل تعديل الملفات.
- افتح فرعًا قصير العمر لكل عمل، ثم Pull Request يشرح الدافع والنطاق والأثر وطريقة التحقق.
- لا ترفع ملفات البيئة أو الفيديو أو بيانات الأشخاص أو الأوزان إلى Git.
- استخدم `CHANGELOG.md` لتسجيل التغييرات الظاهرة للفريق.

أصبحت المنصة منتجًا تكامليًا لإدارة المشروع وتشغيل النموذج وعرضه. راجع [حزمة التصميم للمراجعة](docs/blueprint/README.md) للاتفاقات والجداول والخطة. المعمارية الأولية أعلاه تخص نواة المجسم؛ لا تصف باك إند المنصة. الجلسات الثماني نقاط مراجعة وليست حصرًا لجلسات التنفيذ.
